# Google検索結果 個人・企業サイト分類

指定Excelのキーワードごとに、Google検索結果1ページ目で確認できる通常の自然検索枠を個人・企業・要確認へ分類し、集計と詳細をExcelへ反映する。

## 使用前に確認すること

1. Excelの対象ファイル、対象シート、キーワード列を特定する。既定値は `サジュエストワード` シートのA列である。
2. 分類前に [references/classification-policy.md](references/classification-policy.md) を読む。
3. Excelへ反映する前に [references/workbook-contract.md](references/workbook-contract.md) を読む。
4. Excelを編集する場合は、利用可能なスプレッドシート用の手順と検証方法に従う。

## 実行範囲

- Google検索画面をブラウザで開き、日本語・日本向けの1ページ目を確認する。
- 通常の自然検索結果、通常の検索結果として表示された動画・口コミ・Q&A・投稿サイトを対象にする。
- 広告、AIによる概要、関連する質問、検索候補、他の人はこちらも検索、ショッピング、ナレッジパネル、通常枠ではないカルーセルは除外する。
- 同じドメインが複数の自然検索枠に出た場合も、枠ごとに1件として記録する。
- 検索結果に表示された順位、サイト名、ドメイン、運営者名、公式表示と一般知識だけで分類する。

## 禁止事項

- 検索結果のリンクを開かない。記事本文、会社概要、運営者情報、FAQを読まない。
- 本文内のキーワード出現回数、記事品質、法人登記を調べない。
- Googleの確認画面やCAPTCHAを自動で解決・回避しない。別検索エンジンや別IPで代用しない。
- 未取得の検索結果を推測で補完しない。
- 入力Excelの元データ列や、管理対象外のシートを変更しない。

## ブラウザ調査

1. 1つのブラウザ状態を継続して使い、キーワードを順番に検索する。並列検索はしない。
2. 検索結果が表示されたことを確認し、必要に応じてページ末尾まで表示して通常の自然検索枠を確定する。
3. GoogleのDOMは変わるため、単一のCSSクラスだけに依存せず、検索結果コンテナ、見出し、リンク、アクセシビリティ情報を照合する。
4. キーワードごとに `rank`、`siteName`、`domain` を記録する。ドメインが表示されない既知のサービスは、検索結果上のサービス名から最小限のドメイン補完をしてよい。
5. 分類ルールに沿って `classification` と `classificationReason` を決める。
6. 1キーワード分の集計と詳細を、累積結果JSONへ直ちに反映する。途中中断時は、そのJSONを再開用の正本にする。

Googleの確認画面が出た場合は、現在の検索タブをユーザー操作用に保持し、解除後に同じ未完了キーワードから再開する。確認画面を自然検索0件として記録してはならない。

## 結果JSONとExcel反映

結果JSONは [references/workbook-contract.md](references/workbook-contract.md) のスキーマに従う。各キーワードについて、次の不変条件を満たすこと。

```text
自然検索対象件数 = 個人件数 + 企業件数 + 要確認件数 = 検索結果詳細の件数
```

Excel反映前に必ず実行する。

```powershell
node scripts/validate-results.mjs --results <results.json>
```

検証に通った累積JSONだけをExcelへ反映する。

```powershell
node scripts/update-workbook.mjs --input <input.xlsx> --results <results.json>
node scripts/verify-workbook.mjs --input <input.xlsx> --results <results.json>
```

`--output <output.xlsx>` を指定した場合だけ別ファイルへ保存する。指定しない場合は、ユーザーが指定した入力Excelを更新する。

## 完了条件

- 入力Excelの全キーワードについて、Google検索結果1ページ目の自然検索枠を実際に確認している。
- 未処理・取得失敗・確認画面中のキーワードを残して完了扱いにしない。
- 詳細行に順位、サイト名、ドメイン、分類、簡潔な判定理由がある。
- 個人・企業・要確認の合計と詳細件数が一致する。
- Ameblo、note、Yahoo!知恵袋の結果は、`.jp`規則より優先して個人になっている。
- Excel保存後に、主表・検索結果詳細・要確認シートの値、書式、数式エラーを検証する。

## 報告内容

最終報告では、対象キーワード数、自然検索対象件数、個人件数、企業件数、要確認件数、出力ファイルを簡潔に示す。要確認が残る場合は、推測ではなく検索結果表示だけでは判定できなかったことを明記する。
