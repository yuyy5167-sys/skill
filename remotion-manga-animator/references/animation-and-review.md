# 動作方式と実画像の確認

## メッシュとレイヤーの選択

| 場面 | 方式と注意 |
| --- | --- |
| 顔を数ピクセル動かす | メッシュの内部を剛体に近く動かす。目と口の内部に境界を通さない。 |
| 首・肩のつながり | 襟や袖など自然な境界の周囲で動きを弱める。関節の丸い蓋や内部線を追加しない。 |
| 指とペン | 指・手・ペンの動く範囲をまとめる。文字を固定する範囲がペン先を押さえて曲げないか確認する。 |
| 本がかばんへ入る | 元の本を除いた背景、手と本の動くレイヤー、かばんの前面の順に重ねる。前面を動かして本を縮ませる代用にしない。 |
| 背景の窓枠が近い | 直線を固定する。動作を減らしても曲がるならレイヤーへ切り替える。 |
| 白以外の吹き出し | 文字を消した同じ色・模様の画像を文字範囲に重ねる。輪郭と尾は原画のまま保持する。 |

メッシュは同じ画像の近傍を連続的に移動させるため、近い背景にも変形が漏れ得る。固定領域を設定しただけで無変形と断言せず、原画と動作の頂点を重ねて確認する。目・口・顔の輪郭の相対位置を保つ。

レイヤー用の `baseImage` は動く物の元の位置を除いた画像にする。動くレイヤーに原画と同じ全面画像を使う場合は、対象を囲う `polygon` で切り抜く。透明素材ならそのまま使える。レイヤーは配列の先頭から奥→手前。同じ `part` を手と持ち物へ指定すれば同じ変換で動く。前景は `part` を指定せず静止させる。隠れていた背景や衣服の補完は必要な範囲に絞り、透明PNGが必要なら透明背景を維持する。

## 動きと読ませ方

1コマにつき主な動作を少数に絞り、始動→動作の頂点→落ち着き→静止を作る。常時揺らす必要はない。顔の移動2〜4px・角度0.5〜1.5度などは約1024px幅原稿の試作例であり、全原稿の固定値ではない。

姿勢の時刻を `floor(frame * poseHz / fps) / poseHz` へ離散化してから計算する。キー間の値を計算しても、出力では離散化した姿勢だけを描く。標準8Hz/24fpsでは3フレームが同じ絵になる。カメラや文字の表示にも同じ視覚時刻を使い、別の連続アニメーションを混ぜない。

字幕・吹き出しは原稿を読んで照合する。複数の返答を最初から同時表示してオチを先に見せない。文字を隠す範囲と、変形を防ぐ吹き出し全体の範囲は別に設定できる。空の輪郭を先に見せる方式が文脈に合わなければ、吹き出し全体を分離して出す。

後から出るセリフは、表示時刻から読む時間が取れるようにする。文字数による見積もりは初期値であり、縦書き、英語、文字の大きさに応じて実再生で調整する。厳密な総尺指定では、読む時間を削って勝手に収めず、構成や動作の尺を調整する。

## 見つかった症状と修正

| 症状 | 原因候補と処置 |
| --- | --- |
| 首や肩に新しい線 | パーツ端の輪郭。塗り・テクスチャの重なりか連続した変形へ変更。 |
| 手が二重 | 元の位置が背景に残っている。レイヤー用の背景を修正。 |
| ペン先だけ曲がる | 固定文字の領域と動く領域の競合。原画を拡大して境界を分ける。 |
| 吹き出しの輪郭が消える | 文字を覆う範囲が広すぎる。文字の範囲に絞り、輪郭と尾を保持。 |
| 目・口が伸びる | 複数の動作領域の重なりや固定領域が顔を横切る。顔を一まとまりで扱う。 |
| 本やかばんが縮む | 重なりを変形だけで代用している。静止前景のあるレイヤー構成へ変更。 |
| 動かしたのに見えない | 移動量が小さい、固定領域が広すぎる、確認時刻が違う。背景を壊さない範囲で修正。 |

## 確認の順序

短い試作では方式ごとの失敗を優先する。全編では各パーツの開始・頂点・終了、文字の表示直前・直後・読了、コマ間を確認する。圧縮前の同じ姿勢のフレームを比較し、動く期間の次の姿勢に変化があることも確認する。停止演出中の同一フレームは不具合にしない。

原稿の線・印を新しい不具合と誤認しないよう原画像と比較する。静止画による確認、動画の通し再生、音の試聴、メディア情報の検査は区別して報告する。再生が最後まで進んだ事実だけを、全フレームの目視や試聴の証明にしない。
