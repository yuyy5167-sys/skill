# Google検索・競合調査手順

## 1. 検索条件

利用可能なブラウザ操作手段でGoogle検索を実際に実行し、次を記録する。

- キーワードの原文
- 調査日時とタイムゾーン
- 国・地域、検索言語、端末条件
- Googleのログイン状態と、パーソナライズ抑制の可否
- Google直接確認の可否
- 自然検索の確認範囲
- 2ページ目相当の実施有無と理由

地域・言語パラメータや非パーソナライズ設定を利用できる場合は適用する。ただし、現在地や個人差を完全には除けないことを注記する。

Googleを直接確認できない場合、通常のWeb検索を補助として使ってよいが、その並びをGoogle順位とみなさない。「Google検索結果を直接確認していない」「調査未完了」と明記する。

ローカル意図が強く、対象地域が「日本」だけでは判定できない場合は、都道府県・市区町村を確認してから狙い目度を確定する。

## 2. 自然検索順位の数え方

「自然検索1位から10位」は、通常のWebページへ遷移する自然検索結果カードを画面上から順に数える。

順位へ含めないもの:

- 広告
- AI Overview
- 強調スニペット内の引用枠
- ローカルパック
- 商品・ショッピング枠
- 動画・画像カルーセル
- 「他の人はこちらも質問」

これらはSERP機能として別記する。

重複・系列の扱い:

- 強調スニペットと通常結果に同じURLがある場合、通常結果カードの位置だけを順位とする
- 同じURLの完全重複は1件として扱う
- 同一サイトの異なるURLは別順位として記録する
- サイト数は、同一運営ブランド・系列をまとめた件数も併記する
- サブドメインや別ドメインでも同一運営主体と確認できる場合、ページ順位を保持したまま系列としてまとめる
- 無限スクロールでは、自然検索結果カードの通算11件目から20件目を「2ページ目相当」とする
- 表示仕様により安定して数えられない場合、URLと表示順だけを記録し、厳密順位は「不明」とする

最初の2結果ページ相当の自然検索結果が20件未満の場合は、確認できた全件を調査し、件数と理由を記録する。存在しない順位を補わない。

## 3. SERP機能

自然検索結果とは別に、表示されたものだけを記録する。

- AI OverviewまたはAI Modeへの導線
- 強調スニペット
- 「他の人はこちらも質問」
- 関連検索・検索候補
- 動画、画像、ニュース
- ローカルパック、地図
- 商品・ショッピング枠
- 掲示板、Q&A、フォーラム
- 公式サイトへのナビゲーション結果

SERP機能から検索意図と自然検索のクリック余地を考察するが、機能の存在だけで順位可能性を断定しない。

## 4. 調査範囲と本文確認

### 観察範囲

基本範囲は、Googleで連続して表示される最初の2結果ページ相当とする。通常は自然検索1〜20位に相当するが、表示件数、無限スクロール、地域・端末条件によって異なるため、実際に確認した範囲を記録する。1ページ目相当と2ページ目相当の順位帯を混同しない。

最初の2結果ページ相当を観察できない場合は、確認できた自然検索結果と理由を記録する。11〜20位相当の結果は、1〜10位相当の結果を置き換えるためではなく、検索意図、競合の多様性、記事設計上の不足を把握する補助材料として扱う。

### 本文確認の手順

各自然検索結果について、通常の閲覧を1回試行する。確認状況は次のいずれかで記録する。

- **本文確認済み**: 本文と、必要に応じて見出し・運営者情報を確認できた
- **一部確認**: 見出し、冒頭、公開情報など一部だけ確認できた。確認できた範囲だけを分析根拠に使う
- **本文未確認**: 本文を確認できなかった。タイトルやスニペットから本文内容を推測しない

CAPTCHA、ログイン制限、アクセス制限、タイムアウトなどに対して回避を続けない。未確認ページもSERP観察記録から削除せず、順位・URL・未確認理由を残す。

### 観察完了と分析完了

- `SERP観察完了`: Google直接確認、最初の2結果ページ相当の観察、各結果の順位・タイトル・URL・本文確認状況の記録が完了した状態
- `競合見出し分析 可`: 独立運営者3以上の主要分析ページで、本文見出しの採取、対象範囲の分離、論点の正規化、共通論点、独自性候補まで根拠付きで完了した状態
- `競合見出し分析 限定`: 個人・小規模の独立運営者が3未満、または一部確認不能だが、確認範囲と確信度を示して記事方向を判断できる状態
- `競合見出し分析 不可`: 主検索意図、共通論点、または重要な競合不足を根拠付きで判断できない状態
- `見出し設計引渡し 可`: 主検索意図、記事方針、重要論点、対象範囲、根拠がそろい、構成を変える未解決事項がない状態
- `見出し設計引渡し 条件付き`: 未確認事項が影響する仮見出しを特定でき、それ以外の構成は安定している状態
- `見出し設計引渡し 不可`: 未確認事項が主検索意図、記事方針、記事分割、または重要見出しを変え得る状態
- `G1引渡し可`: 主検索意図、ペルソナ、記事方針、根拠、未確認事項がそろい、新規記事の見出しを変える未解決事項がない状態
- `G1引渡し可否`は既存の「可・不可」の2値を維持する。推奨方針が新規作成または意図を分けた新規作成で、`見出し設計引渡し 可`の場合だけ「可」とする。リライト、統合、別キーワード、追加確認、または条件不足では「不可」として理由を記録する
- 本文未確認が多く、主検索意図や記事方針を根拠付きで決められない場合は、`SERP観察完了`でも`G1引渡し不可`とし、判定保留にする

## 5. 競合分類

各自然検索結果を、運営規模と検索対象との関係の二軸で分類する。

### 軸A: 運営規模・主体

| 分類 | 主な確認材料 |
|---|---|
| 個人 | 個人名義、著者プロフィール、運営者情報、問い合わせ先 |
| 小規模事業者 | 会社概要、事業内容、拠点数、公開された運営体制 |
| 中規模・専門組織 | 会社概要、専門編集体制、事業範囲、サイト規模 |
| 大手企業 | 全国的事業規模、著名ブランド、大規模媒体、会社情報 |
| 公的・教育機関 | 国、自治体、独立行政法人、大学・学校などの設置主体 |
| プラットフォーム | Q&A、掲示板、SNS、投稿サービスの運営者 |
| 不明 | 運営者または規模の根拠を確認できない |

### 軸B: 検索対象との関係・ページ役割

| 分類 | 意味 |
|---|---|
| 公式・一次情報 | 商品、サービス、制度、組織を直接提供・管轄する主体 |
| 第三者専門情報 | 第三者の立場で解説・比較する専門サイトや専門家 |
| 第三者メディア・アフィリエイト | 比較、集客、広告収益などを目的とする媒体 |
| UGC・個人投稿 | 投稿者による質問、回答、体験談、SNS投稿 |
| 販売・仲介 | EC、代理店、予約、紹介など取引を仲介するページ |
| 不明 | 検索対象との関係を確認できない |

ドメイン末尾、サイト名、見た目だけで分類しない。会社概要、運営者情報、著者情報などの証拠を添える。確認できなければ「不明」とする。

### 集計用語

- 「個人・小規模サイト」: 軸Aが「個人」または「小規模事業者」の自然検索結果
- 「個人・小規模運営の第三者ページ」: 軸Aが個人・小規模で、かつ軸Bが第三者専門情報または第三者メディア・アフィリエイトの結果
- 「大手・公的・公式結果」: 軸Aが大手企業または公的・教育機関、もしくは軸Bが公式・一次情報である結果の和集合
- 一つの結果が複数条件を満たしても、複合条件では1件と数える
- 順位ページ数は結果カード単位、競合運営者数は同一ブランド・系列をまとめて別集計する
- 二軸のどちらかが不明なら、複合条件へ推定加算せず不明件数として別記する

## 6. サイト側とページ側の評価

「ドメインパワー」を単一のGoogle公式指標として扱わず、次へ分ける。

### サイト側の競争力の代理情報

- 運営主体の規模と知名度
- サイトの専門領域とキーワードの一致
- サイト全体の記事規模
- 著者・編集体制・運営者情報の明確さ
- SERP内の同一サイト露出
- 実際に取得できた第三者SEO指標

### ページ側の品質

- 検索意図への一致
- 正確性と一次情報への接続
- 更新日と鮮度
- 実体験、独自画像、独自データ、検証方法
- 判断に必要な比較軸
- タイトル、導入、見出し、本文の分かりやすさ
- 情報不足、曖昧さ、古さ

### 定性判定

| 評価対象 | 高 | 中 | 低 | 不明 |
|---|---|---|---|---|
| サイト側 | 明確な運営規模に加え、テーマ一致、運営・著者情報、SERP露出など複数の強い証拠がある | 専門性や運営実態は確認できるが、規模・知名度・露出の一部が限定的 | 個人・小規模で大きなブランド露出がなく、強い代理情報が少ない | 運営者または判断材料を確認できない |
| ページ側 | 主意図を満たし、根拠、具体性、鮮度、独自価値、説明構造に大きな欠落がない | 主意図は満たすが、根拠、具体性、鮮度、独自価値の一部に改善余地がある | 主意図の取りこぼし、重大な古さ、根拠・具体性不足など明確な弱点が複数ある | 本文未確認または材料不足 |

各判定に最低2つの観察事実を付ける。2つ未満なら「不明」とする。「低」は今回のキーワードに対する競争力の代理判定であり、運営者の人格評価ではない。

## 7. 深掘り

個人・小規模サイトが上位にある場合、次を優先して確認する。

- 検索意図へ合う理由
- タイトルと導入で示す約束
- 疑問を解決する順序
- 比較表、画像、体験談、検証、FAQの使い方
- 情報の鮮度と根拠への接続
- 小規模サイトが再現できる点と模倣すべきでない点

この節はサイト単位の定性分析に限定する。見出し全文は見出し採取表、共通度と競合不足は競合論点マトリクス、対象サイトで実現可能な差別化は独自性候補表へ記録し、この節へ重複転記しない。

大手・公式・公的サイトは除外せず、正確性、一次情報、説明順序、図表、比較方法、FAQなどを別枠で整理する。大手サイトが上位である理由をドメイン規模だけに帰属させない。

## 8. 個人・小規模サイトの見出し分析

### 8.1 分析対象の選定

見出しの共通度を集計する対象を次のように分ける。

- **分析候補ページ**: 軸Aが個人または小規模事業者、軸Bが第三者専門情報または第三者メディア・アフィリエイトで、主検索意図に合い、本文を確認できたページ
- **主要分析ページ**: 分析候補から独立運営者を優先して選び、共通度の分母へ含めるページ
- **補助ページ**: 主要分析ページと同一運営者だが、別の重要意図を扱うため補助的に確認するページ。共通度の分母、掲載ページ数、独立運営者数へ含めない

選定は次の順序で行う。

1. 分析候補ページを自然検索順位順に並べる
2. 同一運営者では最上位ページだけを主要分析ページとして優先する
3. 独立運営者を優先し、最大5ページを主要分析ページにする。3以上存在する場合は少なくとも3ページを分析する
4. 同一運営者の追加ページは、別の重要意図を扱う場合だけ補助ページにする
5. 独立運営者が3未満の場合も1運営者1主要ページを維持し、存在する全独立運営者の最上位ページを主要分析ページにする

候補総数、主要分析ページ数、補助ページ数、独立運営者数、除外ページと理由を記録する。個人・小規模サイトがなければ無理に認定せず、大手・公式中心のSERPであることを記録する。

### 8.2 見出し採取

主要分析ページと補助ページについて、次を採取する。

- 記事タイトル
- ページに存在する場合はH1
- 記事本文内の全H2・H3
- 本文確認状態
- 公開日・更新日を確認できた場合はその日付
- 適用範囲が変わり得る商品・サービス、版・世代、対象者、地域、提供期間、情報時点

ナビゲーション、フッター、関連記事、広告、サイト共通部品は記事本文の見出しへ数えない。検索意図と無関係な本文見出しは採取記録に残し、分析対象外とした理由を記録する。本文未確認または一部確認で見出し階層を確認できない場合、存在しないH2・H3を推測しない。

### 8.3 対象範囲の分離

見出しを意味単位へまとめる前に、違いが事実または検索意図を変える場合だけ対象範囲タグを付ける。

- 商品・サービスの違い
- 現行版と旧版、世代、プラン
- 通常提供と期間限定企画
- 対象年齢、学年、会員区分などの対象者
- 地域や制度の適用範囲
- 料金、仕様、制度などの情報時点

対象範囲が異なる見出しは、言葉が似ていても同じ論点へ合算しない。対象範囲を確認できなければ「対象範囲未確認」とする。

### 8.4 正規化と共通度

採取した各見出しを、一つの正規化論点または分析対象外へ対応づける。正規化論点は、競合の表現ではなく、読者の疑問または説明目的を短く要約する。

- 主要分析ページが3以上の独立運営者から成り、2以上の独立運営者で確認した論点を「共通論点」とする
- 独立運営者が3未満の場合、繰り返し確認した論点は「共通候補」とし、確信度を低とする
- 同一運営者の補助ページは補助根拠として表示できるが、集計を増やさない
- 共通度は「主要分析ページN件中M件・独立K運営者」と表示し、順位・URL・対象範囲を対応づける

共通論点は分析対象内の観察結果であり、Googleの順位要因、Web全体の必須見出し、記事への自動採用条件ではない。採否は主検索意図、読者の判断、一次情報、記事範囲から決める。

### 8.5 競合不足と独自性候補

主要分析ページについて、次を競合不足の候補として確認する。

- 読者の判断に必要な情報の欠落または説明不足
- 古い情報、更新時点不明、競合間の矛盾
- 通常提供と期間限定企画など対象範囲の混同
- 料金、仕様、制度などで公式根拠への接続がない
- メリットだけで注意点、向かない人、比較基準が不足している
- 読者の段階や対象者が区別されていない

競合不足が見つかっても、それだけで独自価値と確定しない。主検索意図または読者の行動判断に必要かを確認し、必要な根拠と対象サイトで利用できる根拠・資産を照合する。

| 実現可能性 | 判定基準 |
|---|---|
| 確認済み | 利用可能な根拠・資産と使用条件を確認できた |
| 条件付き | 必要な根拠・資産と入手方法は特定したが、取得、確認、ユーザー提供などが残る |
| 未評価 | 対象サイト情報、ユーザー独自情報、資産の有無が未提供または不明 |
| 不可 | 必要な根拠・資産が存在しない、利用できない、事実と矛盾する、または記事範囲外であることを確認した |

Web全体で誰も書いていないとは断定せず、「確認した主要分析ページでは十分に扱われていない独自性候補」と表現する。候補が見つからない場合も、その結果と理由を記録する。

## 9. 検索意図と既存記事

KNOW・DO・BUY・GOは補助分類とし、実際のSERPから次を分析する。

- 最初に知りたい結論
- 検索直前の状況
- 情報収集、比較検討、申込み直前などの段階
- 上位結果に共通する形式と論点
- 意見が分かれる論点
- 関連検索・質問欄の追加疑問
- 公式情報と体験談を求める意図の比率
- 最新性、地域性、画像、動画、実演の必要性

意図が分かれる場合、主意図と副意図を分け、無理に1記事へ統合しない。

既存記事一覧がある場合、調査キーワードの意図・必須論点と、提供・閲覧できるタイトル、URL、概要、見出し、本文を照合する。

| 判定 | 基準 |
|---|---|
| 重複の可能性が高い | 主意図が同じで、結論または必須論点の大半が重なる |
| 一部重複の可能性 | 副意図または一部論点が重なるが、役割を分けられる余地がある |
| 明確な重複なし | 主意図と記事の役割が異なる |
| 判定不能 | タイトルやURLだけなど、材料が不足する |

重複候補があれば、新規作成を自動推奨せず、「既存記事へ統合」「既存記事をリライト」「意図を分けて新規作成」「別キーワードを検討」「追加確認」から根拠付きで提案する。本文未確認の記事をタイトルだけで重複と断定しない。一覧未指定時は「未指定」とする。

### 見出し設計前の情報充足度

Google検索と競合調査は、記事目的、対象サイト、既存記事、実体験などの任意入力が不足していても進める。SERPの確認後、タイトル・H2・H3案を出す前に、次を確認する。

- 記事の目的と、読者に取ってほしい行動
- 主ペルソナの検索直前の状況と検討段階
- 対象サイトの専門領域と、利用できる既存資産
- 既存関連記事と、主記事・関連記事の役割分担
- ユーザーが保有する実体験、独自写真、独自データ、検証結果

不足情報によって、主検索意図、記事の結論、対象読者、1記事で扱う範囲、既存記事への統合判断、または実体験を示す表現の採否が変わる場合だけ、見出し案を確定する前にユーザーへ確認する。それ以外の不足は「未指定」とし、影響する見出しを示したうえで仮案を出す。既存記事一覧がなければ、検索意図の分割候補は提示できるが、カニバリゼーションは「未評価」とする。

検索意図が分かれる場合は、各意図について次を判定する。

- 主記事で扱う必須意図
- 同じ読者の判断を助けるため主記事へ含める副意図
- 別記事に分ける意図
- 既存記事へ統合する意図。既存記事一覧がある場合だけ判定する

### 関連キーワードの追加調査

関連キーワードを追加検索するのは、次のいずれかに該当し、見出し設計または記事分割の判断が変わる可能性がある場合に限る。

- 主意図と副意図を分けられない
- 重要なH3またはFAQの根拠が不足している
- 関連検索や質問欄に同じ疑問が繰り返し現れる
- 口コミ、料金、変更方法などを主記事へ含めるか別記事にするか判断できない
- 学年、地域、商品区分などによって事実が変わる可能性がある

追加キーワードは、元の指定キーワードを置き換えず、基礎SERPに表示された関連語または未解決の判断に直接必要な語を使う。新しい必須論点、記事分割判断、一次情報の確認先が増えなくなった時点で終了し、調査した追加キーワードと終了理由を記録する。検索語を際限なく広げない。

## 10. 例外と停止条件

| 状況 | 対応 |
|---|---|
| Googleへアクセスできない | 代替検索の使用を明記し、Google順位を確定せず「調査未完了」とする |
| CAPTCHA・ログイン制限 | 回避を続けず、確認範囲と制限を報告する |
| 最初の2結果ページ相当の自然検索結果が20件未満 | 表示された全件を確認し、件数と理由を記録する |
| ページ本文を取得できない | スニペットから推測せず「本文未確認」とする |
| 動画・PDF・ツール | 形式を記録し、確認できる内容だけを分析する。存在しないH2/H3を作らない |
| 検索意図が曖昧 | 意図別に整理し、記事方針が変わる場合はユーザーへ確認する |
| 個人・小規模の独立運営者が3未満 | 1運営者1主要ページを維持して全独立運営者を分析し、共通論点ではなく共通候補、競合見出し分析は「限定」とする |
| 個人サイトがない | 無理に認定せず、大手・公式中心であることを難度材料にする |
| 現行版、旧版、期間限定企画などが混在 | 対象範囲を分離し、事実が変わるものを同じ論点へ合算しない |
| YMYL | 専門家、公的機関、一次情報、更新性を優先する |
| ローカル・商品・ニュース意図が強い | SERP機能によるクリック余地も評価する |
| 有料SEO指標を取得できない | 推定せず、目視できる証拠だけで定性的に評価する |

## 11. 事実・推測・著作物・プライバシー

- 検索順位は調査時点のスナップショットとして扱う
- 料金、仕様、制度、キャンペーンは公式の一次情報で再確認する
- 競合の見出しや文章を大量転載せず、引用と要約を区別する
- 競合見出しの出現頻度を順位要因または採用理由として単独で使わない
- 補助ページを主要分析ページの分母、掲載ページ数、独立運営者数へ加算しない
- 対象範囲が異なる情報を、表現が似ているという理由で統合しない
- Googleの順位要因を断定せず「寄与していると考えられる要素」と表現する
- 公開UGCは複数投稿の共通傾向を集約し、個人の体験談を一般事実へ拡張しない
- ユーザーが提供していない体験、成果、専門性を記事の独自価値として扱わない。第三者の体験を使う場合は、ユーザー自身の体験であるかのような一人称表現や見出しを作らない
- 独自写真や学習記録などを候補にする場合は、利用可能性を未確認のまま前提にせず、個人情報、会員情報、学校名などの写り込み確認を未確認事項へ残す
- 投稿者名、アカウント名、連絡先、住所、学校名、勤務先、病歴など、記事設計に不要な個人情報を転記しない
