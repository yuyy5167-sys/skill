# 現行SEO方針

## 実行時の現在性確認

SEO方針、Google検索機能、AI機能、スパムポリシーは変わりうる。現在性が結論へ影響する場合は、実行時にGoogle Search Centralの公式資料を再確認し、確認日を最終レポートへ記録する。確認できない場合は、古い教材や第三者記事で現在のGoogle方針を確定しない。

## 判断目的ごとの正本

| 判断目的 | 優先する情報源 | 補助情報 | 禁止する扱い |
|---|---|---|---|
| 検索順位・SERP構成 | 調査時点のGoogle検索結果 | 代替Web検索 | 代替検索の並びをGoogle順位とみなす |
| 現行SEO方針 | 最新のGoogle Search Central公式資料 | 旧教材、第三者解説 | 古い数値基準を現行ルールとして採用する |
| 記事中の事実 | テーマの公式サイト、行政、法令、統計、原資料 | 信頼できる二次資料 | 競合記事の主張を未確認で事実とする |
| 検索意図・競合構成 | 実際のSERPと上位ページ | 関連検索、質問欄、集約した公開UGC | 単独記事から検索意図を断定する |
| 対象サイト適合 | ユーザー提供のサイト資料、既存記事、経験・実績 | 公開サイト情報 | 未指定の強みや経験を創作する |
| 第三者SEO指標 | 指標提供元から実際に取得した値 | 目視可能なサイト情報 | 未取得のDA・DR・検索ボリュームを推定する |

## 現行方針として維持する原則

- 読者に役立つ、信頼できる、人を第一にした内容を優先する
- 他ページの要約や言い換えだけで終わらず、独自情報、分析、実体験、検証、判断材料を加える
- タイトルはページ固有で、簡潔かつ内容を正確に示す
- キーワードを自然に使い、完全一致や不自然な反復を強制しない
- Googleが好むとされる固定文字数や固定キーワード密度を目標にしない
- AI利用の有無ではなく、正確性、品質、関連性、独自価値で評価する
- AIで価値の乏しいページを大量生成して検索順位を操作しない
- AI OverviewやAI Modeにも基礎的なSEOと、独自で役立つ非コモディティ情報を優先する。AEO・GEOの「裏技」を別の必須施策として扱わない
- YMYLに該当する医療、法律、金融、安全などでは、一次情報、専門性、更新性、信頼性の要求を高くする
- 第三者SEOツールの指標や予測はGoogle内部データではなく、順位を保証しない

## 旧来ルールの採否

| 考え方 | 採否 | 扱い |
|---|---|---|
| 検索意図を先に調べる | 採用 | SERP全体と上位ページから顕在・潜在意図を分析する |
| 上位記事のタイトル・見出し・論点を確認する | 採用 | 共通論点と不足を集約し、構成を複製しない |
| 一次情報・独自情報・具体例を加える | 採用 | 競合要約を超える価値として重視する |
| 結論を早めに示す | 条件付き採用 | 即答を求める意図の場合に使う |
| 内部リンクを活用する | 条件付き採用 | 対象サイト情報がある場合だけ候補を出す |
| キーワードをタイトル・主要見出しへ入れる | 条件付き採用 | 自然で内容を正確に表す場合に限る |
| 長文・網羅的な記事ほど有利 | 条件付き採用 | 必要論点を満たす。長さそのものを評価しない |
| ドメインパワーが強いほど有利 | 条件付き採用 | サイト側の代理情報の一つとし、ページ品質と分ける |
| 上位が個人サイト中心なら狙い目 | 条件付き採用 | 強い材料だが、検索意図、品質、YMYL、独自価値も確認する |
| タイトル28文字以内 | 固定ルールとして不採用 | 簡潔さと内容の正確さで判断する |
| 1文60文字程度 | SEOルールとして不採用 | 読みやすさの編集目安に限る |
| 特定の本文文字数 | 不採用 | 上位平均から目標文字数を決めない |
| キーワード密度を高める | 不採用 | 不自然な反復を避ける |
| 検索結果件数100万件以下を狙う | 不採用 | 競合難易度の主要指標にしない |
