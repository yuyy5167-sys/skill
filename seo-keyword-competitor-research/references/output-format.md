# リサーチレポート出力形式

見出し順を基本として出力する。該当情報がない項目は削除せず、「未指定」「未確認」「該当なし」「判定不能」のいずれかを理由付きで示す。

## 1. 検索条件

```text
- キーワード:
- 調査日時・タイムゾーン:
- 対象地域・言語:
- 端末条件:
- Googleのログイン状態・パーソナライズ抑制の可否:
- 確認範囲: 最初の2結果ページ相当 / 実際に確認できた範囲
- 2ページ目相当の観察実施有無と理由:
- Google直接確認の可否:
- SERP観察完了: 可 / 不可
- 競合見出し分析: 可 / 限定 / 不可
- 見出し設計引渡し: 可 / 条件付き / 不可
- G1引渡し可否（親スキルのQuality Gate完了）: 可 / 不可
- 本文確認: 本文確認済み__件 / 一部確認__件 / 本文未確認__件
- 本文未確認の主な理由:
- 個人・小規模の分析候補: __件 / __独立運営者
- 主要分析ページ: __件 / 補助ページ: __件
- 現行SEO公式資料の確認日:
- 検索結果の変動・パーソナライズに関する注記:
```

## 2. 結論サマリー

```text
- 支配的な検索意図:
- 主ペルソナの要約:
- SERP参入余地: 高・中・低・判定保留
- 対象サイト適合度: 高・中・低・未評価
- 各判定の確信度: 高・中・低
- 最大の参入機会:
- 最大の難点:
- 推奨方針: 新規作成 / 既存記事へ統合 / 既存記事をリライト / 意図を分けて新規作成 / 別キーワードを検討 / 追加確認
```

## 3. SERP構成

自然検索以外に実際に表示されたSERP機能と、それが示す検索意図・クリック余地を整理する。表示されなかった機能を推測で追加しない。

## 4. 競合一覧

| 順位 | タイトル | URL | 運営規模・主体 | 検索対象との関係 | サイト側の競争力 | ページ側の品質 | 主な検索意図 | 強み | 弱み | 本文確認 | 分析対象 | 未確認理由 | 分類・評価根拠 |
|---:|---|---|---|---|---|---|---|---|---|---|---|---|---|

- サイト側とページ側は「高・中・低・不明」
- 各定性判定に最低2つの観察事実を付ける。足りなければ「不明」
- 外部SEO数値がなければ無理に数値化しない
- 同一運営ブランド・系列は、ページ順位を残したまま識別できるようにする

## 5. 競合見出し・論点分析

### 5.1 見出し採取表

本文確認済みの個人・小規模サイトから選んだ主要分析ページと補助ページについて、記事本文内の全H2・H3を記録する。

| 順位 | URL | 独立運営者 | ページ役割 | 本文確認 | 対象範囲 | 記事タイトル | H1 | 本文のH2・H3 | 分析対象外の見出し・理由 |
|---:|---|---|---|---|---|---|---|---|---|

- ページ役割: 主要 / 補助
- ナビゲーション、フッター、関連記事、広告、サイト共通部品は本文見出しへ含めない
- 検索意図と無関係な本文見出しは記録に残し、分析対象外とした理由を示す
- 本文未確認または一部確認で見出し階層を確認できなければ推測しない

### 5.2 競合論点マトリクス

上位記事の見出しをそのまま並べず、対象範囲が同じで意味が近い論点を統合し、根拠ページと対応づける。

| 正規化論点 | 主要N件中の掲載M件 | 独立K運営者 | 対応する順位・URL | 対象範囲 | 主意図への重要度 | 上位記事の充足状況 | 競合不足 | 公式確認の必要性 | 記事への採否・理由 |
|---|---:|---:|---|---|---|---|---|---|---|

- `N`は主要分析ページ数、`M`は主要分析ページ内の掲載ページ数、`K`は独立運営者数
- 補助ページは補助根拠として表示できるが、N・M・Kへ含めない
- 主要分析ページが3独立運営者以上あり、2独立運営者以上で確認したものを「共通論点」とする
- 独立運営者が3未満の場合、繰り返し確認したものは「共通候補」とし、確信度を低とする
- 主意図への重要度: 必須・補助・別記事候補
- 記事への採否: 採用・条件付き採用・不採用。理由を付ける
- 多くの競合にあるという理由だけで採用しない
- 対象範囲が異なる事実を同じ論点へ合算しない
- 競合見出しの表現や配列をコピーしない

### 5.3 独自性候補表

競合不足と、対象サイトが実際に追加できる価値を分けて判定する。

| 競合不足 | 対象範囲 | 読者に必要な理由 | 競合上の根拠 | 必要な一次情報 | 利用可能な根拠・資産 | 実現可能性 | 記事での使い方 | 未確認事項 |
|---|---|---|---|---|---|---|---|---|

- 実現可能性: 確認済み / 条件付き / 未評価 / 不可
- 対象サイト情報や独自資産が未提供なら「未評価」とし、独自価値として確定しない
- Web全体で誰も書いていないとは断定せず、「確認した主要分析ページでは十分に扱われていない独自性候補」とする
- 独自性候補が見つからない場合も、その結果と理由を記録する

## 6. 個人・小規模サイトの深掘り

該当する各サイトについて整理する。

- 検索意図への対応方法
- タイトルと導入で約束している内容
- 説明の順序、比較表、画像、体験談、検証、FAQの使い方
- 体験、画像、検証の有無と、情報の鮮度・根拠への接続
- 小規模サイトが再現できる点と模倣すべきでない点
- 推測を含む箇所

見出し全文は見出し採取表、共通度と競合不足は競合論点マトリクス、対象サイトで実現可能な価値は独自性候補表を参照し、この節へ重複転記しない。

該当サイトがなければ、その事実を明記する。

## 7. 大手・公式・公的サイトから参考にする点

- 正確性と一次情報
- 説明順序
- 比較表、図解、FAQ
- 読者が判断しやすい表現
- 小規模サイトが再現できるか

## 8. 検索意図

- 主意図
- 副意図
- 読者が最初に必要とする答え
- 比較・判断に必要な情報
- 関連検索・追加疑問
- 別記事に分けるべき意図

## 9. ペルソナ

[persona-and-opportunity.md](persona-and-opportunity.md)の項目で主ペルソナを出力する。副ペルソナは、同じ記事で扱う合理性がある場合だけ出力する。

追加項目:

```text
- ユーザー指定の想定読者: 指定内容 / 未指定
- SERP由来ペルソナとの整合性: 一致・一部一致・不一致・判定不能・未指定
- 一致点・相違点:
- 記事設計への影響と推奨対応:
```

## 10. 狙い目度

- 個人・小規模サイトの自然検索結果数
- 同一系列をまとめた個人・小規模運営者数
- 運営規模別の結果数
- ページ役割別の結果数
- 軸Aが個人・小規模、かつ軸Bが第三者である結果数
- 軸Aが大手・公的、または軸Bが公式・一次情報である結果の和集合数
- 二軸のどちらかが不明で複合条件へ算入できなかった結果数
- プラス材料
- 難度材料
- 独自価値を用意できるか
- SERP参入余地と確信度
- 対象サイト適合度と確信度。対象サイト情報がなければ「未評価」
- 判定根拠に使った順位、URL、観察事実

ページ数と同一系列をまとめた運営者数を混同しない。

## 11. 記事作成に必要な情報

```text
- 記事の目的:
- 読者に取ってほしい行動:
- 読者へ最初に伝える結論:
- 必ず答える質問:
- 必須論点:
- 比較軸:
- 一次情報で確認すべき事実:
- 実体験・独自データが必要な箇所:
- ユーザーが保有する実体験・独自情報: あり / なし / 未指定
- 構成に影響する不足情報:
- 不足情報によって変わる見出し:
- 競合に不足している情報:
- 独自の切り口候補:
- 対象サイト情報がある場合、そのサイトで実現可能な切り口:
- 読者の不安・反論への回答:
- 記事で避ける内容:
- 既存記事一覧の指定: あり / 未指定
- カニバリゼーション候補: 記事名・URL・重複する意図または論点
- 重複判定: 重複の可能性が高い / 一部重複の可能性 / 明確な重複なし / 判定不能 / 未指定
- 推奨対応: 新規作成 / 既存記事へ統合 / 既存記事をリライト / 意図を分けて新規作成 / 別キーワードを検討 / 追加確認
- 重複判定の根拠と確信度:
- 主記事で扱う意図:
- 別記事へ分ける意図:
```

## 12. 記事構成案

- 見出し案の成熟度: 仮案 / 条件付き / 執筆準備完了
  - 仮案: 主意図または記事範囲を変えうる任意入力が不足している
  - 条件付き: 一部の見出しが、未確認の実体験、独自情報、一次情報などの入手を条件としている
  - 執筆準備完了: 記事目的、主意図、対象読者、記事範囲、重要な事実の確認先がそろい、構成を変える未解決事項がない。上位表示を保証する意味ではない
- 仮のSEOタイトル案3案
- 仮の推奨タイトルと理由
- 導入文で約束する内容
- 仮のH2/H3構成案
- 比較表、図解、画像の候補
- FAQ候補
- メタディスクリプション案

各H2と、事実・比較・実体験を約束する重要なH3について、次の根拠表を付ける。単なる補足説明のH3まで機械的に表へ追加しない。

| 見出し案 | 対応する検索意図 | ペルソナの疑問 | 根拠の種類 | 独自価値 | 未確認事項 | 採否・成熟度 |
|---|---|---|---|---|---|---|

- 根拠の種類: 公式・一次情報 / 競合ページ / 集約したUGC / ユーザー提供の実体験・独自情報 / 分析上の推測
- 採否: 採用 / 条件付き採用 / 別記事候補 / 不採用
- 競合に存在するという理由だけで見出しを採用しない

タイトル文字数、見出し数、本文文字数を固定しない。検索意図と読者の理解に必要な範囲で設計する。

ここで示すタイトルとH2/H3は、リサーチ根拠を次工程へ渡すための仮案である。最終的な文言、階層、重複整理、品質判定は見出し作成スキルへ委ねる。

## 13. 根拠・未確認事項

- 参照URL
- 確認日
- 公式情報、競合情報、分析上の推測の区分
- アクセスできなかったページ
- 更新日を確認できなかった情報
- 記事作成前に追加確認が必要な事項
- 追加調査した関連キーワードと、その必要性・終了理由

- 個人・小規模サイトの候補数と選定方法:
- 主要分析ページ・補助ページの選定理由:
- 本文・見出しを確認した方法:
- 未確認・分析対象外とした範囲:
- 共通論点が記事方針へ与えた影響:
- 独自性候補が記事方針へ与えた影響:

## 品質ゲート

### SERP観察完了

次をすべて満たした場合だけ「SERP観察完了: 可」とする。

- [ ] 指定キーワードをGoogleで実際に検索した
- [ ] 調査日時、地域、言語、端末、確認範囲を記録した
- [ ] 広告と自然検索結果を区別した
- [ ] 最初の2結果ページ相当を可能な範囲で観察した。通常の1〜20位と異なる場合は、実際の表示範囲と理由を記録した
- [ ] 各自然検索結果の順位・タイトル・URL・本文確認状況を記録した
- [ ] 本文未確認ページの理由を記録し、タイトルやスニペットから内容を推測していない
- [ ] 2ページ目相当の観察実施有無と理由を記録した
- [ ] 運営規模・主体と検索対象との関係を別々に分類し、根拠を示した
- [ ] 同一運営ブランド・系列を識別し、ページ順位と独立運営者数を混同していない

### 競合見出し分析

次の判定基準を使う。

- `可`: 独立運営者3以上の主要分析ページで、対象範囲分離、見出し採取、正規化、共通論点、独自性候補まで完了した
- `限定`: 個人・小規模の独立運営者が3未満、または一部確認不能だが、範囲と確信度を示して記事方向を判断できる
- `不可`: 主検索意図、共通論点、または重要な競合不足を根拠付きで判断できない

「可」または「限定」とする前に、次を確認する。

- [ ] SERP観察完了が「可」である
- [ ] 個人・小規模の分析候補数、主要分析ページ数、補助ページ数、独立運営者数を記録した
- [ ] 主要分析ページを1運営者1ページで選び、補助ページをN・M・Kへ含めていない
- [ ] 個人・小規模サイトが3独立運営者未満なら全独立運営者の最上位ページを分析し、共通候補・確信度低とした
- [ ] 個人・小規模サイトがなければ無理に認定せず、その事実を明記した
- [ ] 主要・補助ページの記事タイトル、存在するH1、本文内の全H2・H3を採取した
- [ ] サイト共通部品と分析対象外の本文見出しを分け、除外理由を記録した
- [ ] 本文未確認または一部確認ページから見出しを推測していない
- [ ] 必要な場合、商品・サービス、版・世代、対象者、地域、提供期間、情報時点を対象範囲として分離した
- [ ] 採取した各見出しを一つの正規化論点または分析対象外へ対応づけた
- [ ] 共通論点または共通候補に、N・M・K、順位・URL、対象範囲を対応づけた
- [ ] 共通論点を順位要因またはWeb全体の必須見出しと断定していない
- [ ] 競合見出しの表現や配列をコピーしていない
- [ ] 競合不足と、対象サイトで実現可能な独自価値を分けた
- [ ] 独自性候補に対象範囲、読者に必要な理由、根拠、実現可能性、未確認事項を付けた
- [ ] 対象サイト情報や独自資産が未提供なら、実現可能性を「未評価」とした
- [ ] 個人・小規模サイト深掘りをサイト単位の定性分析に限定し、各表と重複させていない

### 見出し設計引渡し

次の判定基準を使う。

- `可`: 主検索意図、記事方針、重要論点、対象範囲、根拠がそろい、構成を変える未解決事項がない
- `条件付き`: 未確認事項が影響する仮見出しを特定でき、それ以外の構成は安定している
- `不可`: 未確認事項が主検索意図、記事方針、記事分割、または重要見出しを変え得る

「可」または「条件付き」とする前に、次を確認する。

- [ ] 競合見出し分析が「可」または「限定」である
- [ ] サイト側の競争力とページ側の品質を分け、高・中・低の判定に2つ以上の観察事実を付けた。不足時は「不明」とした
- [ ] 検索意図をSERPの実態から分析した
- [ ] ペルソナの各項目に根拠があり、架空属性を追加していない
- [ ] 想定読者があれば整合性、相違点、記事設計への影響を出力し、未指定なら「未指定」とした
- [ ] 既存記事一覧があれば重複候補、根拠、対応案を出力し、未指定なら「未指定」とした
- [ ] 既存記事一覧がない場合、カニバリゼーションを「未評価」とし、存在しない記事を推測していない
- [ ] SERP参入余地のプラス材料と難度材料を両方示した
- [ ] 対象サイト情報がなければ対象サイト適合度を「未評価」とした
- [ ] 見出し案の成熟度と、構成に影響する不足情報を示した
- [ ] 各H2と重要なH3を、検索意図、根拠、独自価値、対象範囲へ対応づけた
- [ ] ユーザーが提供していない実体験、成果、写真、専門性を創作していない
- [ ] 主記事で扱う意図と、別記事へ分ける意図を区別した
- [ ] 事実、競合の主張、分析上の推測を分けた
- [ ] UGC利用時に不要な個人情報を転記していない
- [ ] 参照URL、未確認事項、調査方法、記事への活用判断を残した
- [ ] 固定文字数、キーワード密度、検索結果件数だけでSEO判断していない

### G1引渡し可否（親スキルのQuality Gate完了）

次をすべて満たした場合だけ「G1引渡し可否（親スキルのQuality Gate完了）: 可」とする。

- [ ] 見出し設計引渡しが「可」である
- [ ] 推奨方針が「新規作成」または前提のそろった「意図を分けて新規作成」である
- [ ] 見出しを変える未解決事項がない

G1の値は既存の「可・不可」を維持する。推奨方針がリライト、統合、別キーワード、追加確認、または条件不足の場合は「不可」とし、理由を具体的に示す。親スキルを使用しない実行では互換情報として出力するだけで、後工程は`見出し設計引渡し`を使う。

SERP観察が完了しても後続条件を満たせない場合は、各ゲートを独立して判定し、不足事項を具体的に示す。Googleを直接確認できない場合は、従来どおり「調査未完了」とする。
